# Shop Management System

It is a C++ console based shop management system to demonstrate the concept of Object Oriented Programming (OOP). Basic shop management operations are represented in the project, which are Product, Admin and Customer.


## Key Features

This course is an introduction to concepts of Object Oriented Programming in classes.
Use of arrays to manage products
- Make a separate Product class, Admin class and Customer class.
- Console-based user interface

## System Requirements

Requirement: Windows 10/11 
- **Programming Language:** C++
The C++ compiler has to be compatible with the GCC/G++ compiler.
The C++ Programming Language to use is C++11 or later, as needed, in the source.

No 3rd party libraries are required to be installed.

## Installation and Execution


Requirements

Windows operating system

Dev-C++ IDE

A compatible Dev-C++ software installation which contains a C++ compiler.

### 1. Clone the Repository

```bash
git clone https://github.com/Muhammad-Khalid-CS/Shop-Management-System.git
```

### 2. Click to open the Project Directory.

```bash
cd Shop-Management-System
```

### 3. Compile and Run

Compile the program:

```bash
g++ -std=c++11 main.cpp -o shop_management
```

On Windows, run:

```bash
shop_management.exe
```



## Project Purpose

This project is aimed towards the academic learning and implementation of some basic concepts of C++ and OOP.
